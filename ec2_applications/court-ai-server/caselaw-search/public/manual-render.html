📚 คู่มือการใช้งานระบบ Legal Search & Citation App

ระบบค้นหาคำพิพากษาและสร้างชุดเอกสารอ้างอิงคดีอัจฉริยะ (SLegalTools Research Hub)

ระบบนี้ออกแบบมาเพื่อช่วยให้นักกฎหมาย ทนายความ และผู้ที่สนใจ สามารถค้นหาข้อมูลทางกฎหมาย วิเคราะห์ประเด็น และสรุปรูปคดีได้อย่างรวดเร็วด้วยพลังของปัญญาประดิษฐ์ (AI)

1. หน้าจอหลักและการค้นหาทั่วไป (Home & Search)

เมื่อเข้าสู่ระบบ คุณจะพบกับหน้าจอหลักที่ออกแบบมาให้ใช้งานง่าย พร้อมระบบค้นหาที่ครอบคลุม:

ภาพที่ 1: หน้าจอหลักของระบบ Legal Search Hub
💡 เคล็ดลับการค้นหาอัจฉริยะ (AI Deka Search)
คุณสามารถพิมพ์คำถามด้วยภาษาธรรมชาติ เช่น "ทำร้ายร่างกายจนบาดเจ็บสาหัส มีความผิดอย่างไร" ระบบ AI จะทำการวิเคราะห์และค้นหาคำพิพากษาศาลฎีกาที่เกี่ยวข้องมาให้ทันทีโดยไม่ต้องจำคีย์เวิร์ด
ภาพที่ 2: หน้าจอแสดงผลลัพธ์การค้นหาคดีศาลฎีกาที่เกี่ยวข้อง

2. การค้นหาตัวบทกฎหมาย (Legal Code Search)

นอกจากการค้นหาคำพิพากษาแล้ว คุณยังสามารถสลับไปที่แท็บ "ค้นหาตัวบทกฎหมาย" เพื่อค้นหามาตราหรือเนื้อหากฎหมายที่ต้องการได้อย่างรวดเร็ว พร้อมแสดงประวัติการแก้ไขและข้อมูลเชิงสถิติของมาตรานั้นๆ

ภาพที่ 3: แท็บค้นหาตัวบทกฎหมาย OCS

3. ผู้ช่วยทนายความ AI (AI Assistant)

ที่แถบเมนูด้านซ้าย คุณสามารถคลิกเข้าสู่ "ผู้ช่วยทนายความ AI" เพื่อพูดคุยและปรึกษาประเด็นข้อกฎหมายได้ ระบบนี้เชื่อมต่อกับ AWS Bedrock (รองรับโมเดล Amazon Nova และ Claude) ซึ่งจะช่วยตอบคำถาม สรุปประเด็น หรือช่วยร่างคำฟ้องได้อย่างชาญฉลาด

ภาพที่ 4: การแชทปรึกษาข้อกฎหมายกับ AI Assistant
📌 หมายเหตุ
ระบบ AI Assistant รองรับการแสดงผลแบบ Streaming ทำให้ข้อความคำตอบจะค่อยๆ ปรากฏขึ้นมาทันทีโดยไม่ต้องรอนาน เหมือนการสนทนาจริง

4. ระบบจัดการ Workspace และ สร้าง Citation Pack

ฟีเจอร์เด่นของระบบนี้คือการรวบรวมคำพิพากษาศาลฎีกาหลายๆ คดี มาจัดทำเป็น ชุดเอกสารอ้างอิงคดีความ (Citation Pack) เพื่อยื่นต่อศาลหรือใช้เขียนสำนวนคดี

วิธีใช้งาน:

  1. ในหน้าค้นหาคำพิพากษา ให้กดปุ่ม "เพิ่มลง Workspace" ที่คดีที่คุณสนใจ
  2. ไปที่เมนู "Workspace" ทางด้านซ้าย คุณจะเห็นรายการคดีที่ถูกบันทึกไว้
  3. ระบุ ประเด็นข้อพิพาท (Issue) และข้อเท็จจริงเพื่อประมวลผล
  4. เลือก Engine ที่ต้องการใช้งาน (AWS Bedrock หรือ SLegalTools AI)
  5. กดปุ่ม "สร้างชุดเอกสารอ้างอิงคดี"
ภาพที่ 5: จัดการรายการคดีและกรอกข้อมูลประเด็นข้อพิพาทใน Workspace

หลังจากสั่งสร้าง ระบบจะทำการรวบรวมคดีทั้งหมดมาวิเคราะห์ร่วมกับประเด็นที่คุณกรอก และจัดหน้าผลลัพธ์เป็นเอกสารอ้างอิงที่เรียบร้อยสวยงาม สามารถนำไปคัดลอกหรือดาวน์โหลดต่อได้ทันที

5. การตั้งค่าระบบ (Settings)

เมนูตั้งค่าช่วยให้คุณสามารถปรับแต่งการทำงานของแอปพลิเคชันให้เข้ากับความต้องการของคุณได้ รวมถึงตรวจสอบสถานะการเชื่อมต่อ API และ AWS ของคุณ

ภาพที่ 6: หน้าการตั้งค่าระบบ ขนาดตัวอักษร และประวัติ API
⚠️ ข้อมูลสำคัญด้านความปลอดภัย
การตั้งค่ารหัส API Key และการตั้งค่าหน้าจอจะถูกจัดเก็บไว้ในเบราว์เซอร์ของคุณอย่างปลอดภัยด้วย LocalStorage ทำให้มีความเป็นส่วนตัวสูงและไม่ต้องตั้งค่าใหม่เมื่อเปิดโปรแกรมครั้งถัดไป
